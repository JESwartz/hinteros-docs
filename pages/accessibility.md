# Accessibility

<!-- description: The accessibility settings of HinterOS: text size, high contrast, focus marker, reduce motion and typed passwords. -->

Go to Settings → Accessibility. The group has five settings: Text size, High contrast, Focus marker, Reduce motion and Show typed passwords.

Each profile has its own accessibility settings. A change applies at once, on the home screen and on the on-screen keyboard. The settings do not change apps, Steam or games.

| Setting | Values | Default |
|---|---|---|
| Text size | 100%, 120%, 140% or 160% | 100% |
| High contrast | Off or On | Off |
| Focus marker | Ring, Glow or Bar | Ring |
| Reduce motion | Off or On | Off |
| Show typed passwords | Off or On | Off |

## Text size

Text size makes all text larger. A sample sentence below the values shows the size. The layout makes room for the larger text.

At 140% and 160%, the on-screen keyboard does not show the line with the button names.

## High contrast

High contrast uses a black background and white text. The focus marker and the highlights are yellow. Borders are thicker.

## Focus marker

The focus marker shows which item is highlighted. Each style uses a shape, not only a colour:

- Ring: A thick white ring with a dark gap around the item.

- Glow: A thin ring with a soft glow around the item.

- Bar: A thick bar below the item.

The highlighted item also becomes a little larger. A preview below the values shows the three styles.

## Reduce motion

Reduce motion stops the animations:

- The highlighted item does not become larger.

- Items do not slide or fade.

- The progress animations stop.

- On the screen saver, the logo moves only one time each minute. The clock does not fade.

## Show typed passwords

The strip above the keys of the on-screen keyboard shows what you type. In a password field, the strip shows dots. Only the newest character shows, for about one second. This keeps passwords off the TV.

Set Show typed passwords to On to show passwords as text in the strip. Other text fields always show the text.

## The profile picker

The profile picker shows before a profile starts. It uses the accessibility settings of all profiles on the picker:

- The largest Text size of these profiles.

- High contrast, if one of these profiles uses it.

- Reduce motion, if one of these profiles uses it.

The picker always uses the Ring focus marker. Refer to [Profiles](profiles.md).

## Other settings that help

- To change which button does which action, go to Settings → Controller → Buttons. Refer to [Settings](settings.md).

- To make the pointer slower or faster, go to Settings → Controller → Pointer.

- To stop the screen saver, set Settings → Display and sound → Screen saver → Start after to Off.

- If the TV cuts off the picture edges, use Check the picture edges in Settings → Display and sound.
